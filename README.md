# [Fantasy Basketball](https://fantasybasketball.xyz)

Weekly fantasy basketball: pick a 7-player lineup, score points from real NBA stats, and climb the
global and league leaderboards.

```bash
cp .env.example .env   # fill in keys
npm install
npm run tests          # also: npm run typecheck, npm run lint
```

`app/` = front end (Next.js), `functions/` = backend (Appwrite Functions).
Docs: `doc/REQUIREMENTS.md`, `ARCHITECTURE.md`, `plans/ROADMAP.md`, `AGENTS.md`.
